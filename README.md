# Orato ASR Server v2

Realtime streaming + batch speech recognition server for Qwen3-ASR, built for
telecalling voice agents (Hindi/Hinglish). Designed to run on Kaggle GPUs and
be exposed through a Cloudflare quick tunnel.

## What changed vs v1

| Area | v1 | v2 |
|---|---|---|
| Streaming decode | vLLM native incremental streaming (`streaming_transcribe`) - **could hang the CUDA worker forever**, stalling all sessions | Removed entirely. Partials use windowed re-decode via the same `model.transcribe` path as batch (proven reliable) |
| GPU wedge handling | None - a hung decode silently stalled everything | Watchdog on every GPU submission; wedges produce an `error` event and a clean exit(70) so the supervisor restarts the process |
| WS audio intake | Per-chunk `load_audio()` container sniffing (soundfile/av probe every 100ms chunk) | Direct PCM16 LE conversion with numpy |
| Turn-taking defaults | 400ms partial cadence / 800ms silence flush | Telecalling-tuned: 150ms partial cadence / 400ms silence flush |
| Ops visibility | `/health` only | `/health` includes uptime, active sessions, queue depth, cumulative stats |

## Wire protocol

Connect: `ws(s)://<host>/ws/transcribe?language=Hindi`

Client sends:
- binary frames: raw **PCM16 little-endian mono @ 16kHz** (no WAV header)
- text frames: `{"action": "ping"}` | `{"action": "flush"}` | `{"action": "reset", "language": "..."}`

Server events (JSON): `connected`, `speech_start`, `partial`, `final`, `speech_end`, `error`.

The client can send `flush` when its local VAD detects end-of-speech to get
finals faster than the server-side 400ms silence window.

## REST API

- `GET /health` - readiness + operational stats
- `GET /api/v1/model-info`
- `POST /api/v1/transcribe` - multipart `file` (+ optional `language`, `context`) for encoded files (wav/mp3/m4a...)

## Run locally (CUDA GPU)

```bash
pip install -r requirements.txt
export ASR_MODEL=Qwen/Qwen3-ASR-0.6B HF_TOKEN=...   # optional overrides
python -m app.server
```

## Run on Kaggle

Use `deploy/notebook.ipynb` (generated by `deploy/create_nb.py`). It clones
this repo, fixes FlashInfer JIT linking, starts a Cloudflare quick tunnel,
waits for engine readiness, and auto-restarts the server if it ever exits
(including watchdog-triggered exit code 70). Requires a Kaggle Secret named
`HF_TOKEN`. Choose accelerator **GPU T4 x2**.

## Configuration (env vars)

| Variable | Default | Purpose |
|---|---|---|
| `ASR_MODEL` | `Qwen/Qwen3-ASR-0.6B` | Model id or local path |
| `ASR_BACKEND` | `auto` | `auto` \| `transformers` \| `vllm` |
| `DEVICE` / `TORCH_DTYPE` | `auto` | e.g. `cuda` / `float16` |
| `STREAM_CHUNK_DURATION` | `0.15` | Seconds between interim partials |
| `SILENCE_DURATION_FLUSH` | `0.4` | Trailing silence that finalizes an utterance |
| `STREAM_CONTEXT_DURATION` | `3.0` | Rolling context window for partials |
| `VAD_ENERGY_THRESHOLD` | `0.003` | RMS threshold for speech detection |
| `DECODE_TIMEOUT_SEC` | `20` | Watchdog ceiling per GPU submission |
| `GPU_EXIT_ON_WEDGE` | `true` | Exit(70) on wedge so supervisor restarts |
| `GPU_WORKERS` | `1` | Serialized GPU worker threads |
| `PORT` / `HOST` | `8000` / `0.0.0.0` | Bind address |

## Smoke test

```bash
python scripts/ws_smoke_test.py wss://<tunnel>.trycloudflare.com sample.wav
```
Streams the file in realtime chunks and prints all events; exits non-zero if
no `final` arrives.
